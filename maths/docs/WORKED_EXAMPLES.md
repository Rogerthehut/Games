# Worked examples and pictures: coverage

Generated by `npm run audit:worked`. For every maths topic: the share of questions that come with a picture, either a figure shown with the question or the method drawn in the solution (column layout, number line with hops, bar model, grid, bus stop, chunking, table and so on).

Topics: 202. Picture on every question: 168. On most: 26. On some: 5. None: 3.

Topics with a picture on only some questions are ones where one form of question (often a single-step recall question) has nothing worth drawing: counting right angles, naming a shape, reading one value off a table.

Topics with no picture today are conceptual multiple-choice questions where there is nothing to draw: which loci or construction step comes next, one-tailed or two-tailed tests, and naming a sampling method.
